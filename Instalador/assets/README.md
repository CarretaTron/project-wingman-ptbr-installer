# Interface resources

These are the original resources supplied for the Project Wingman PT-BR installer:

- `banner.jpg`: background artwork.
- `logo.png`: Project Wingman logo.
- `launcher.ico`: executable and window icon.

The build script embeds these files directly in the interface executable. No image processing or network retrieval is performed during the build.

Project Wingman branding and artwork belong to their respective rights holders. Inclusion here documents the resources used by the fan installer and does not grant a license to third-party artwork.
